# BubbleSearch — правила работы для Claude

Сайт поиска связей кошелька Solana со списком Axiom. Состояние, архитектура и план — в `PLAN.md`; читать его перед началом работы и обновлять после.

## Оркестрация (обязательно)

Основная сессия — оркестратор: проектирует, принимает решения, проверяет результат. Исполнение отдавать субагентам (инструмент Agent) на самой младшей модели, которой хватит для задачи.

| Модель | Что поручать |
|---|---|
| `haiku` | Механика без решений: поиск по коду, сводка логов, запуск и наблюдение за долгими скриптами, переименования, тексты интерфейса, рутинные правки по точному описанию. |
| `sonnet` | Реализация по готовой спецификации: компоненты интерфейса, эндпоинты, тесты, рефакторинг в пределах модуля, проверка в браузере. |
| `opus` (сама сессия) | Алгоритм и пороги в `server/analyze.ts`, контракт `shared/types.ts`, разбор данных Helius, решения со спорными компромиссами, итоговая проверка. |

Как поручать:
- Бриф самодостаточный: какие файлы, что сделать, что считать готовым, чего не трогать. Субагент не видит этот разговор.
- Сначала зафиксировать контракт (`shared/types.ts`, формат API), потом раздавать работу: параллельные исполнители не должны править одни и те же файлы.
- Независимые задачи запускать параллельно.
- Результат субагента — отчёт, а не доказательство: смотреть дифф, запускать `npm test`, `npm run typecheck`, `npm run build`, проверять в браузере.
- Задачи, требующие оценки качества алгоритма на живых данных, не делегировать.

## Команды

```bash
npm run dev          # API :8787 + Vite :5173
npm test && npm run typecheck && npm run build
npm run index-tracked -- --recent=200                 # индекс списка в кэш (≈105 тыс. кредитов Helius)
npm run index-tracked -- --recent=200 --ttl-days=7    # обновить индекс: только новые переводы
node --env-file=.env scripts/eval.ts --n=20 --seed=1  # калибровка на именах с 2+ кошельками (≈15 тыс. кредитов)
```

- `preview_start` в этой среде не поднимает процессы. Сайт для пользователя запускать в его терминале (`run_in_terminal`, `npm run dev`); сервер там перезапускается сам при правках `server/`, интерфейс — через HMR.
- Ключ Helius в `.env` — бесплатный тариф: `getTransfersByAddress` работает, Wallet API (метки, identity) отвечает 403.
- Действия, тратящие много кредитов Helius (тысячи запросов), согласовывать с пользователем.

## Соглашения

- Интерфейс и сообщения — на русском. Комментарии в коде — на русском.
- Node 24+ запускает `.ts` напрямую; сервер без фреймворков, БД — встроенный `node:sqlite`.
- `data/axiom-wallets.json` — список пользователя, не перезаписывать в проверках.
